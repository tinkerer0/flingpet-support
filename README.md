# FlingPet

FlingPet is a desktop toy for macOS and Windows: jelly balls you pull back and fling around your screen. They bounce off the edges of the window you launched them in.

This repository holds FlingPet's privacy policy and is the place for support questions and bug reports.

- **Privacy policy:** [PRIVACY.md](PRIVACY.md). FlingPet collects no data.
- **Questions and bug reports:** [open an issue](https://github.com/tinkerer0/flingpet-support/issues).
