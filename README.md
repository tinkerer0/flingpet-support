# Screen Bounce

Screen Bounce was called FlingPet until October 2026. / 예전 이름은 FlingPet입니다(2026년 10월 변경).

Screen Bounce is a desktop toy for macOS and Windows: jelly balls you pull back and fling around your screen. They bounce off the edges of the window you launched them in.

This repository holds Screen Bounce's privacy policy and is the place for support questions and bug reports.

- **Privacy policy:** [PRIVACY.md](PRIVACY.md). Screen Bounce collects no data.
- **Questions and bug reports:** [open an issue](https://github.com/tinkerer0/flingpet-support/issues).
